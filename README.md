# Minton Video Library

**배드민턴 자세 분석을 위한 유튜브 영상 다운로드·관리 프로그램 (V1.1)**

Python **파일 한 개**(`minton_video_library.py`)에 GUI, 다운로드 대기열, 동영상 검색·재생, 자막 탐색 및 메모 저장을 구현한 Windows 로컬 프로그램입니다. 사용자별 설정과 기록은 SQLite에 보관합니다.

> 설치를 처음 진행한다면 **[INSTALL.md](INSTALL.md)** 부터 읽으세요. V1.1은 Windows에서 YouTube 다운로드 전체 과정을 완료한 통합 검증본이 아니라, 실제 Windows 환경에서 점검하면서 개선할 초기 버전입니다.

## 핵심 기능

| 구분 | 기능 |
| --- | --- |
| URL 등록 | YouTube 단일 영상·재생목록 링크를 여러 줄로 입력해 대기열 등록 |
| 재생목록 | `watch?v=...&list=...` 도 목록으로 판정. 재생목록 메타데이터 확인 후 개별 순차 작업 생성 |
| 다운로드 | yt-dlp로 **항상 한 번에 영상 1개** 다운로드 |
| 다운로드 간격 | 파일 처리 후 다음 파일까지 기본 **20초**, 0~3600초 변경 |
| 저장 위치 | 기본 `D:\99.유튜브다운\minton.youtube` (GUI에서 변경 및 설정 보존) |
| 폴더 분류 | 단일 영상: `채널명\영상`; 재생목록: `채널명\재생목록명\영상` |
| 영상 품질 | 사용자 지정 `avc1` / 최대 1080p / `mp4a` 우선 설정 유지 |
| 자막 | 한국어 수동 및 자동 자막 다운로드·SRT 변환(제공되는 경우) |
| 영상 메타데이터 | yt-dlp의 `.info.json` 저장 |
| 작업 제어 | 시작·재개, 현재 영상 완료 후 일시정지, 즉시 중단, 실패 항목 재시도 |
| 기존 파일 | 파일 검색·경로 재연결·누락 감지(15초)·전체 폴더 자동 검색(60초), 기존 메모 보존 |
| 라이브러리 | 검색·채널 필터·누락 영상 숨김/표시·조절 가능한 열 너비(저장)·툴팁 |
| 동영상 재생 | 내장 플레이어, 타임라인 이동, 0.5~2.0배속, 음량 조절, 기본 플레이어로 열기 |
| 자막 탐색 | 비슷한 이름/동일 영상ID SRT 여러 개 선택, 자막 전체 목록 및 큰창, 검색, 더블클릭 구간 재생 |
| 파일 관리 | 영상/연관 SRT/info.json 파일 이동·한글 이름 변경·휴지통 삭제, 영상별 메모 보존 |
| 메모 | 영상별 자유 메모와 SQLite 영구 보관, 영상 변경·종료 시 자동 저장 |
| 진행률 표시 | 대기열 개별 진행률 바 및 현재 영상 진행률 바(숫자 병기) |
| 로그 | GUI 로그 및 파일 로그 (5MB 로테이션, 백업 4개) |

## 프로젝트 구조

```text
D:\stockproj\minton_video_library\
├─ minton_video_library.py   # 실행 소스: Python 파일 하나
├─ README.md                 # 기능, 조작, 저장 정보
├─ INSTALL.md                # 신규 설치, 업데이트, GitHub 안내
├─ .gitignore                # Git에서 제외할 개인정보·미디어·산출물
└─ .venv\                    # 설치할 때 생성되는 로컬 가상환경(추적 제외)
```

저장 폴더 예시 (특정 재생목록은 사용자가 제공한 한국어 이름 매핑 사용. 그 밖의 영상은 한국어 우선 메타데이터에 따름):

```text
D:\99.유튜브다운\minton.youtube\
├─ 하루코치\
│  ├─ 하루코치 - 언더스윙 레슨 [XXXXXXXXXXX] - 2026-01-09.mp4
│  ├─ 하루코치 - 언더스윙 레슨 [XXXXXXXXXXX] - 2026-01-09.ko.srt
│  └─ 하루코치 - 언더스윙 레슨 [XXXXXXXXXXX] - 2026-01-09.info.json
├─ 윤이콕TV\
│  └─ 물A조라고 놀리지말아요\
│     ├─ 윤이콕TV - 레슨 1 [96Y3Airgf6M] - 2026-01-09.mp4
│     └─ 윤이콕TV - 레슨 1 [96Y3Airgf6M] - 2026-01-09.ko.srt
└─ 다른채널\
   └─ 다른채널 - 레슨 제목 [YYYYYYYYYYY] - 2026-01-12.mp4
```

SQLite DB 및 로그는 소스 폴더가 아니라 **`%LOCALAPPDATA%\MintonVideoLibrary\`** 에 있습니다.

```text
%LOCALAPPDATA%\MintonVideoLibrary\
├─ library.db
├─ library.db-wal        # SQLite 실행 중 생성될 수 있음
├─ library.db-shm        # SQLite 실행 중 생성될 수 있음
└─ logs\
   ├─ minton_video_library.log
   └─ minton_video_library.log.1  (회전 로그가 생긴 경우)
```

메모·설정·다운로드 작업 기록을 백업하려면 프로그램을 **종료**하고 `library.db`를 복사하세요. 다른 컴퓨터로 옮길 때는 다운로드 영상 폴더도 별도로 복사해야 하며, 경로 변경 후에는 라이브러리 항목을 확인해야 합니다. GitHub에는 DB나 동영상이 올라가지 않습니다.

## 빠른 실행 (Windows PowerShell)

Python 3.12, Deno, FFmpeg 설치 및 PATH 설정 후:

```powershell
cd D:\stockproj\minton_video_library
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install -U PySide6 "yt-dlp[default]"
.\.venv\Scripts\python.exe minton_video_library.py
```

설치 및 GitHub 업로드까지 상세한 순서는 [INSTALL.md](INSTALL.md)를 참고하세요.

## 프로그램 사용법

1. 상단의 **저장 폴더**를 확인하거나 **찾기**로 변경합니다. 변경된 위치는 다음 실행 때 유지됩니다.
2. **간격 (초)** 을 설정합니다. 기본 20초이며, 다운로드 시작 시의 값이 해당 작업 진행 중 유지됩니다.
3. 영상 주소 또는 재생목록 주소를 한 줄에 하나씩 붙여넣고 **대기열에 추가**를 누릅니다. `watch?v=...&list=...`도 전체 재생목록으로 인식합니다. 특정 폴더명을 원하면 주소 입력창 아래의 **채널 폴더명(선택)**, **재생목록 폴더명(선택)**을 기입한 후 등록하세요.
4. **▶ 다운로드 시작 / 재개**를 누릅니다. 재생목록은 먼저 개별 영상 URL로 펼쳐집니다.
5. 중단 방법을 선택합니다. **Ⅱ 일시정지**는 현재 파일이 완료된 뒤 다음 작업 앞에서 멈추고, **■ 즉시 중단**은 현재 프로세스를 종료합니다. 다운로드 중간 파일 `.part`는 남을 수 있습니다.
6. 실패하거나 다시 시도할 작업을 선택한 뒤 **선택 항목 다시 대기**를 누르고 다시 시작합니다. **선택 대기열 삭제**는 작업 기록만 제거하며 파일과 메모는 삭제하지 않습니다.
7. 기존에 받은 영상까지 관리하려면 **폴더 다시 검색**을 누릅니다. 프로그램 시작 및 이후 약 60초마다 자동 재검색합니다. 외부 탐색기에서 파일을 삭제하면 최대 약 15초 후 기본 라이브러리에서 숨겨지고 메모는 DB에 남습니다. **누락 영상도 표시**로 다시 볼 수 있습니다. 파일을 다른 폴더로 옮겼다면 60초 또는 **폴더 다시 검색** 후 동일 ID로 자동 재연결됩니다(새 위치가 다운로드 루트 안인 경우).
8. 하단 라이브러리의 영상 제목을 클릭하면 우측 플레이어와 메모·자막 내용이 연결됩니다. 영상 행을 더블클릭하면 재생할 수 있습니다.
9. **영상 메모**에서 레슨 요점·자세 수정 사항을 작성합니다. 저장 버튼을 누르거나 다른 영상으로 옮기면 저장됩니다.
10. **전체 자막 / 구간 이동** 탭에서 SRT 파일을 선택해 전체 대사를 읽습니다. **전체 자막 큰창**을 누르면 넓은 창에서 검색하며 볼 수 있습니다. 자막 줄 더블클릭은 미디어의 탐색 가능 준비 상태를 확인한 후 해당 시점부터 재생합니다.
11. **영상 파일 이동**으로 동영상·같은 ID의 자막·메타데이터를 함께 이동합니다. **한글 제목/파일명 변경**은 파일명을 고치고 라이브러리 표시명도 저장합니다. **영상 휴지통 삭제**는 영상과 연관 파일을 휴지통으로 옮깁니다.
12. 라이브러리에서 제목·채널 열 사이의 경계선을 드래그해 원하는 너비로 조절하고, 제목 위에 마우스를 올리면 툴팁으로 전체 내용을 볼 수 있습니다. 열 너비는 다음 실행에도 유지됩니다.

**자막은 영상 위에 합성해 표시하는 방식이 아니라**, 현재 자막을 플레이어 하단의 텍스트 영역에 보여주고 전체 자막 목록을 제공합니다. 한국어 자막이 없는 영상은 SRT가 생성되지 않습니다.

## yt-dlp 옵션

원래 사용하던 아래 명령의 실질적인 영상·자막 품질 옵션을 유지합니다. 이 프로그램은 한 개씩 다운로드하도록 개별 항목에 `--no-playlist`도 적용합니다.

```text
--js-runtimes deno --remote-components ejs:npm
-f "bv[vcodec^=avc1][height<=1080]+ba[acodec^=mp4a]/b[vcodec^=avc1][height<=1080]"
--merge-output-format mp4
--write-subs --write-auto-subs --sub-langs "ko.*" --convert-subs srt
--write-info-json --no-playlist --continue
--extractor-args "youtube:lang=ko"
-P "<사용자가 선택한 저장 루트>"
-o "%(channel)s/%(channel)s - %(title)s [%(id)s] - %(upload_date>%Y-%m-%d)s.%(ext)s" (단일 영상)
-P "<다운로드 루트>\<채널명>\<재생목록명>" -o "%(channel)s - %(title)s [%(id)s] - %(upload_date>%Y-%m-%d)s.%(ext)s" (목록 영상)
```

- `avc1`/`mp4a` 조합이 영상에 없으면, 엄격한 형식 선택 조건 때문에 실패할 수 있습니다. 임의로 WebM/AV1로 대체하지 않습니다.
- 자동 자막은 한국어 자막이 제공되는 경우에만 받을 수 있습니다.
- 이미 DB에 등록되어 있고 파일도 존재하는 영상은 중복 다운로드를 생략합니다. V1.0에서 `채널명\영상` 구조로 받았던 파일은 해당 재생목록 작업으로 다시 등록되면 `채널명\재생목록명\영상`으로 자동 재분류됩니다. **여러 서로 다른 재생목록에 중복 포함된 영상은 추가 복사하지 않고** 기존 파일을 사용하며, 필요하면 파일 이동 기능을 이용하세요.
- `--extractor-args youtube:lang=ko`로 한국어 메타데이터를 우선 요청합니다. **YouTube에 한국어 제목이 없는 외국어 영상은 자동 번역되지 않습니다.** 이때는 한글 제목/파일명 변경 버튼을 사용하세요. 정확한 채널/재생목록 폴더명은 URL 등록 시 수동 지정할 수 있습니다.
- `PLX1IndZwkjj0`는 사용자가 직접 제공한 채널·재생목록 한글명 매핑을 적용합니다: `윤이콕TV\물A조라고 놀리지말아요\`. 별도 입력한 수동 폴더명이 항상 더 우선합니다.

## GitHub 버전 관리

소스와 문서만 보관하고 대용량 영상·자막·로그·메모 DB는 업로드하지 않는 구성을 권장합니다. [.gitignore](.gitignore)에 제외 패턴이 포함되어 있습니다.

```powershell
cd D:\stockproj\minton_video_library
git init
git branch -M main
git add minton_video_library.py README.md INSTALL.md .gitignore
git status
git commit -m "Update Minton Video Library v1.1"
```

GitHub 저장소 생성/게시 방법은 [INSTALL.md의 GitHub 항목](INSTALL.md#7-github-비공개-저장소에-등록하기)에서 설명합니다.

## 문제 발생 시

문제가 생기면 화면 하단 로그 및 아래 파일을 확인하세요.

```powershell
notepad "$env:LOCALAPPDATA\MintonVideoLibrary\logs\minton_video_library.log"
```

`deno`, `ffmpeg`, `yt-dlp`, 한글 경로, 자막이 보이지 않을 때의 확인 순서는 [INSTALL.md의 문제 해결](INSTALL.md#8-문제-해결)에 정리했습니다.

## 개발 원칙

- 프로그램 기능과 **기존 로그를 삭제하지 않고** 필요한 기능만 추가·개선합니다.
- Python 소스 파일 시작 부분에 전체 기능 목록과 변경 사항을 주석으로 정리합니다.
- 기존 GUI 레이아웃, 저장 위치, 메모, 대기열 동작을 최대한 호환되게 유지합니다.
- 배드민턴 자세 분석 프로그램과 연동할 때 동영상 ID, 타임스탬프, 자막 및 메모를 활용하도록 확장합니다.
